# AI Tool Usage

## AI Tool Used
ChatGPT

## Purpose of Usage

1. Debugging
   - Used ChatGPT to understand and resolve errors encountered
     during Python, Docker, Kubernetes and API implementation.

2. Kubernetes and GKE
   - Used ChatGPT for understanding Kubernetes deployment,
     HPA configuration and troubleshooting pod scheduling issues.

3. Cloud Logging
   - Used ChatGPT to construct and debug Google Cloud Logging queries.

4. Stress Testing
   - Used ChatGPT to understand and configure wrk for testing
     the API with more than 2000 concurrent connections.

5. Drift Detection
   - Used ChatGPT to understand input drift and create an analysis
     comparing training data with the generated prediction dataset.

6. Documentation
   - Used ChatGPT to organize technical explanations and document
     the implementation and troubleshooting process.

## Declaration

AI tools were used as assistance for learning, debugging,
implementation guidance and documentation. The implementation
was executed and verified by me.
